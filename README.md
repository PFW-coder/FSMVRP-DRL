# Deep Reinforcement Learning for Solving the Fleet Size and Mix Vehicle Routing Problem

This is a deep reinforcement learning-based method that solves an important variant of the routing problems, the Fleet Size and Mix Vehicle Routing Problem (FSMVRP). In the FSMVRP, both the fleet configuration and vehicle routing must be determined. For vehicles of various types, both fixed cost and variable cost are heterogeneous.


## Dependencies

* Python>=3.9
* NumPy
* SciPy
* [PyTorch](http://pytorch.org/)>=1.7
* tqdm
* tensorboard_logger
* Matplotlib (optional, only for plotting)
